Encryption method: Repeating-key XOR
Key: ledger7
Key length: 7 bytes

Flag: CASE{ledger_xor_cracked}

Solve method:
1. Estimate key length using index-of-coincidence (pairwise Hamming distance across all block pairs)
2. Split ciphertext into blocks by key length
3. Break each block as single-byte XOR using English letter frequency scoring
4. Recombine recovered bytes into the full key
5. XOR ciphertext with recovered key to get plaintext
