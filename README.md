# IE3132-CTF-PlayBox

A 6-stage CTF platform for IE3132, taking players through OSINT, Networking, Web Security, Forensics, Cryptography, and a final Linux privilege-escalation challenge. Built on CTFd with Docker/VM-isolated stages, chained together so each solved flag unlocks the next.
